# ActionBar+

<img src="./assets/fabric.svg" width="16" height="16" alt="fabric" />&nbsp;**For Minecraft 1.21.8 Fabric**
Shows in-game time and weather above the hotbar
Format:

> <img src="./assets/clock.svg" width="16" height="16" alt="icon" />&nbsp;12:30 | <img src="./assets/rain.svg" width="16" height="16" alt="icon" />

## Build

```bash
git clone https://rich_beluga/actionbar # clone repo
cd actionbar
./gradlew build
```

Result: `build/libs/actionbar-{version}.jar`
